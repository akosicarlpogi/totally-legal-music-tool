How to use:

1. git clone https://github.com/USERNAME/YoutubeDownloader.git
2. cd YoutubeDownloader
3. py -m pip install -r requirements.txt
4. copy and paste one or multiple YT links on "main.txt", for example:
      https://yt.com//link1
      https://yt.com//link2
      https://yt.com//link3
5. save, then open vscode terminal
6. run "py download.py"
